# Campus Connect FD

A comprehensive campus service marketplace platform connecting students with local service providers. Built with modern React and designed for seamless service discovery, booking, and management.

## 🚀 Features

- **Multi-Role Authentication**: Student, Vendor, and Admin user roles
- **Service Marketplace**: Browse and book campus services with real-time availability
- **Advanced Search & Filtering**: Find services by category, price, rating, and more
- **Booking Management**: Complete booking lifecycle with status tracking
- **Vendor Dashboard**: Service management and booking oversight
- **Admin Panel**: User management, service approvals, and analytics
- **Responsive Design**: Mobile-first design with dark theme
- **Real-time Notifications**: In-app notifications for bookings and updates
- **Payment Integration**: M-Pesa and bank transfer support

## 🛠️ Tech Stack

- **Frontend**: React 19.1.1 with Vite
- **Routing**: React Router DOM v7.9.5
- **Styling**: Tailwind CSS v3.4.3 with custom design system
- **Animations**: Framer Motion v12.23.24
- **Forms**: React Hook Form v7.65.0
- **HTTP Client**: Axios v1.13.1
- **Date Handling**: Day.js v1.11.18
- **Icons**: React Icons v5.5.0

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/your-username/campus-connect-fd.git
cd campus-connect-fd
```

2. Install dependencies:
```bash
npm install
```

3. Start development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

## 🔧 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
